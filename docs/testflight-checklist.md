# クックポップ TestFlight 実機チェック表

TestFlight で入れたクックポップを iPhone で開き、次を確かめる。気になったことは「メモ」に書いて Claude に伝える。

| | 見ること | どうなればよいか | 結果 | メモ |
|---|---|---|---|---|
| 1 | 起動・文字・アイコン | ホーム画面のアイコンがクックポップのもので、開くとポンが出る。文字が丸ゴシックで出る（機内モードでも出る）。起動した直後に文字が別の字体からぱっと変わるちらつきがない | ☐ | |
| 2 | 動画の再生 | カードの中で動画が再生できる。再生できないときは、黒い枠に「エラー153」などが出たあと、「この動画はアプリの中では再生できません」と「YouTube で開く」に切り替わり、押すと Safari か YouTube アプリが開く。黒い枠のまま何も切り替わらなければ不具合 | ☐ | |
| 3 | 登録の自動入力 | 登録の画面で YouTube のリンクを貼ると、料理の題が自動で入る | ☐ | |
| 4 | クリップボードから貼る | 登録画面の『クリップボードから貼る』を押すと、YouTube でコピーしたリンクが入って題が自動で埋まる（押したときだけ『ペーストを許可』が出る） | ☐ | |
| 5 | 作った！ | 料理で「作った！」を押すと、きろくのカレンダーに印が付く | ☐ | |
| 6 | 保存 | 料理と記録を入れたあと、アプリを上にスワイプして閉じ、開き直しても料理と記録が残っている | ☐ | |
| 7 | 画面の端 | 上のノッチ・下のホームバーと、ボタンや文字が重ならない | ☐ | |
| 8 | 暗い見た目 | iPhone を暗い見た目（ダークモード）にしても、文字が読めて、色が崩れない | ☐ | |
| 9 | バックアップ | 書き出すと共有シートが出て、「ファイルに保存」で保存できる。そのファイルを読み込む（ファイル選択）と、料理と記録が戻る | ☐ | |
| 10 | 動画が止まる | 動画を再生している途中で別のタブに移ると、動画の音と映像が止まる | ☐ | |
| 11 | 読み上げ（VoiceOver） | 読み上げ（VoiceOver）をオンにして きめて！ を押したとき、決まった料理名が読み上げられるか | ☐ | |
| 12 | 暗い設定の上端 | iPhone は明るい設定のまま、アプリの設定で「暗い」にしたとき、画面上端の時計などが読めるか | ☐ | |
| 13 | 共有から登録 | YouTube アプリの動画で「共有」→（並びに無ければ「その他」）→「クックポップ」を押すと「クックポップに送りました」のカードが出る。カードの「クックポップで開く」を押すと、クックポップが開いて献立帳の登録画面がそのリンクで埋まり、題が自動で入る。「OK」で閉じた場合は、次にクックポップを開いたときに同じく登録画面が開く | ☐ | |
| 14 | スクロールと長押し | きめる画面が上下に動かない。献立帳・きろくは中だけスクロールし、下のタブは動かない。文字を長押ししても青く選ばれない（入力欄は選べる・貼れる） | ☐ | |
| 15 | キーボード | 登録・編集の画面で、メモ欄や名前欄を押してキーボードが出ても、入力欄が隠れない | ☐ | |
| 16 | ふきんの色 | 設定でふきんの色（たまご・トマト・抹茶・ソーダ・いちご・ぶどう）を切り替えると、ギンガムとハンコの色がすぐ変わる。閉じて開き直しても選んだ色のまま。暗い見た目でも崩れない | ☐ | |
| 17 | マイタグ | 自分のタグ（マイタグ）を作って料理に付けると、献立帳の絞り込みに出て、選ぶとその料理だけが残る。名前を変える・消すと料理の側にも反映される | ☐ | |
| 18 | バナーの場所 | どのタブでも、広告のバナーが画面のいちばん上（時計のすぐ下）に出る。見出しや料理カードがバナーに隠れず、スクロールしても中身がバナーの裏にもぐらない | ☐ | |
| 19 | バナーが隠れるとき | 動画を流すとバナーが消え、「きめて！」で別の結果に替えると戻る。設定を開くと消え、閉じると戻る。文字を入力中は消える | ☐ | |
| 20 | 追跡の確認 | 入れ直して初めて開いたとき「追跡を許可しますか」が出る。どちらを選んでも使える | ☐ | |

※ 18〜20：自分の端末では、出た広告を押さない（AdMob で不正なクリックとみなされるおそれ）。AdMob がまだ「要審査」の間は本物の広告が出ないことがあり、そのときはバナーの場所が空かないだけで正常。
