# クックポップ 計画3：ポンの絵と見た目の仕上げ 実装手順書

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 仮の絵だったポンを本物の絵（`docs/mockups/pon.html` で決めたもの）に差し替え、表情と動きを付ける。計画2で後回しにした見た目の細部を仕上げ、アプリのアイコンと起動画面を作る道具を置く。

**Architecture:** 画面側は `Mascot` の受け口（`setMood/setBelly/say/hush` と `data-mood/data-belly`）を使うだけなので、`pon.ts` の中身と CSS を差し替える。絵の SVG と表情の CSS は見本ページ `docs/mockups/pon.html` が唯一の元で、そこから写す。

**Tech Stack:** 計画2と同じ。加えて `@resvg/resvg-js`（SVG → PNG）

**Spec:** `docs/superpowers/specs/2026-10-23-cookpop-design.md`（3.7 初めて開いたとき、4 マスコット、11 確かめ方）

## Global Constraints

- コードのコメント・テスト名・コミットメッセージは日本語。画面の文言も日本語
- ポンの絵（SVG）と表情の CSS は `docs/mockups/pon.html` の `PON` 文字列と `/* ===== ポンの絵のきまり ===== */` から `@media (prefers-reduced-motion…)` までの CSS ブロックを**そのまま写す**（形や色を変えない。クラス名も変えない）
- 絵文字・既製アイコンは使わない
- 色・角丸は `style.css` の変数だけ。影は平らな影。`prefers-reduced-motion: reduce` では動きを止める
- `src/core/` は変えない
- `npm test`・`npm run typecheck`・`npm run build` が通る状態でコミットする

## Review Focus

- 動きを減らす設定 → ポンの動き・結果カードのせり上がりが全部止まり、表情の切り替えだけ残る（Task 1 のテスト：`@media (prefers-reduced-motion)` の中に `animation: none` がある）
- 暗い見た目 → ポンの線はこげ茶のまま（`--pon-ink` 固定）で、卵黄の体の上で見える（Task 1）
- 初めて開いた人（記録なし・最初の8品のまま）→ はじめましての案内が出て、献立帳へ飛べる（Task 2）
- サムネイルが読めない（オフライン・削除された動画）→ 空白ではなく代わりの絵が出る（Task 2）
- アイコン PNG に透明がない（App Store が受け付けない）→ 色の種類 2（RGB）で書く（Task 4 のテスト）

### Task 4: アイコンと起動画面を作る道具（tools/icon）

**Files:**
- Create: `tools/icon/icon.mjs`（アイコンの SVG を返す `iconSvg(): string` と起動画面の SVG `splashSvg(): string`）, `tools/icon/make-assets.mjs`（PNG を書き出す）, `tools/icon/README.md`
- Modify: `package.json`（`"icon": "node tools/icon/make-assets.mjs"`、devDependency `@resvg/resvg-js@2.6.2`）, `.gitignore`（`art/out/` を除外）
- Test: `tests/tools/icon.test.ts`

**Interfaces:**
- `iconSvg()`：1024×1024。クリーム `#FFF6E5` の無地の地に、`docs/mockups/pon.html` の `PON` を中央に大きく（120 の viewBox を 860px 四方に拡大、少し下寄せ。影の楕円は入れない）。表情は「ふつう」、ほっぺは出す。CSS は使えないので、色は属性で直接書く（体 `#FFC43D`、線 `#4A2E1C` 太さ 3、おなか・帽子 `#FFFDF8`、くちばし・足・ほっぺ `#FF8A5B`、ほっぺは `opacity=".75"`）。透明な部分を作らない
- `splashSvg()`：2732×2732 のクリーム無地
- `make-assets.mjs`：`iconSvg()` を 1024 に、`splashSvg()` を 2732 に描き、**透明なしの RGB の PNG**（`../SuperShogi/tools/icon/make-ios-assets.mjs` の `rgbPng`・`chunk`・`crc32` と同じ作り）で `art/out/icon-1024.png`・`art/out/splash-2732.png` に書く。`ios/App/App/Assets.xcassets` があれば `AppIcon.appiconset/AppIcon-512@2x.png` と `Splash.imageset/splash-2732x2732.png`（`-1`・`-2` も）にも書く。`--preview=<フォルダ>` で 60px 版も書く
- `README.md`：使い方（`npm run icon`）と、絵は見本ページから手で写している旨
