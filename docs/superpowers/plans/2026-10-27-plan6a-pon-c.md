# クックポップ 計画6a：ポンを案C（線なし）に差し替える 実装手順書

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** ユーザーが選んだ案C（輪郭線なし・大きなふわふわのコック帽）のポンを、アプリ・小さな顔・アイコンに入れる。

**唯一の元:** `docs/mockups/pon-c.html`（`PON` の SVG 文字列と、`/* ===== ポン（案C）の絵のきまり` から `@media (prefers-reduced-motion…)` までの CSS）。形・色・数値・クラス名を変えずに写す。古い見本 `docs/mockups/pon.html` は使わない。

## Global Constraints
- コメント・テスト名・コミットメッセージは日本語。`src/core/` は変えない
- `Mascot` の受け口（`el`・`setMood`・`setBelly`・`say`・`hush`）、`.mascot` の入れ物と `data-mood`・`data-belly`、`.bubble` は変えない
- 表情の名前は今までどおり：`normal`・`thinking`・`decided`・`happy`・`full`・`sad`・`sleepy`
- `npm test`・`npm run typecheck`・`npm run sync` が通る状態でコミット。main に直接コミットし push してよい

### Task 1: アプリのポンを案C に（pon.ts・pon.css・thumb.ts・テスト）
- `src/app/mascot/pon.ts` の絵を `pon-c.html` の `PON` に、`src/app/mascot/pon.css` を `pon-c.html` の CSS ブロックに置き換える（見本専用の `body`・`.row`・`.grid`・`.big`・`.dark`・`button` などは写さない。`.mascot svg { width:100%… }` は写さず、アプリの style.css の大きさの指定を残す）
- `src/app/thumb.ts` の `PON_FACE`（40×40、小さな顔）を案C の描き方に描き直す：輪郭線なし、卵黄の丸い体、白い帽子の帯（うすい縁 #E2CFAF）、点の目2つ（白い光つき）、ほっぺ、くちばし。色は案C と同じ値
- `tests/app/pon.test.ts` を新しい絵に合わせる：目の6種類は `e-open`・`e-up`・`e-smile`・`e-sad`・`e-sleepy`・`e-star`、`.think`・`.chin`・`.drop`・`.zzz`・`.belly`・`.wing` が2つ・`.hat`、CSS に7つの `[data-mood=…]` と `[data-belly="3"]` と reduced-motion の `animation: none`。線（`stroke`）が帽子と吹き出し・眉・目の線以外に無いこと（体・おなか・羽・足に `stroke` が無い）
- 目で見る：`npm run dev`、内蔵ブラウザで きめて！（考え中→決めた！）、作った！（うれしい）、きろくの小さなポンと日の印、暗い見た目を確かめる。終わったらタブとサーバーを閉じる
- コミット `ポンを案C（線なし・大きな帽子）に差し替える`

### Task 2: アイコンと起動画面（tools/icon）
- `tools/icon/icon.mjs` の `iconSvg()` を案C の「ふつう」で描き直す：`pon-c.html` の `PON` から `shadow`・`think`・`zzz`・`chin`・`drop`・`e-open` 以外の目のグループを除いたものを、クリーム `#FFF6E5` の地の中央に（200 の viewBox を約 880px 四方に拡大し、少し下寄せ）。ほっぺは opacity .55。透明な部分なし
- `npm run icon -- --preview=art/out` を流し、`art/out/icon-1024.png` と `icon-60.png` を Read で開いて、中央にいて縁が切れず、60px でも顔が分かることを確かめる。`ios/App/App/Assets.xcassets` にも書かれる
- `tests/tools/icon.test.ts` が通ること（必要なら帽子の色など新しい絵の検査に直す）
- コミット `アイコンを案C のポンにする`
