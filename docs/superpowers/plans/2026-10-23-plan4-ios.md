# クックポップ 計画4：iPhone 化 実装手順書

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Capacitor 8 でアプリを包み、iPhone だけの部品（消えにくい保存・共有シートでの書き出し・ファイル選択・クリップボード・外のブラウザで開く）を `deps` の差し替えで入れ、GitHub の Mac で TestFlight へ送るワークフローと実機チェック表を用意する。**この計画で手元にできるのは「包み」まで。GitHub にリポジトリを作って上げること・ワークフローの実行はユーザーの確認のあと（別の作業）。**

**Architecture:** 画面は変えない。`src/app/native.ts` にアプリの中だけの部品を集め、`main.ts` が `isNativeApp()` のときだけ本物に差し替える（SuperShogi と同じ）。Web 版（`npm run dev`）はこれまでどおり動く。

**Tech Stack:** `@capacitor/core`・`@capacitor/ios`・`@capacitor/cli` 8.5.2、`@capacitor/preferences` 8.0.1、`@capacitor/app` 8.1.2、`@capacitor/clipboard` 8.0.1、`@capacitor/share` 8.0.3、`@capacitor/filesystem` 8.1.5、`@capawesome/capacitor-file-picker` 8.1.1（すべて exact）

**Spec:** `docs/superpowers/specs/2026-10-23-cookpop-design.md`（2 決めたこと、5.4 保存、8 iPhone 化、11 確かめ方）

## Global Constraints

- コードのコメント・テスト名・コミットメッセージは日本語
- アプリの ID は `com.maosundev.cookpop`、表示名は `クックポップ`、版は `0.1.0`、`webDir` は `dist`、`ios.contentInset` は `never`、起動画面と `backgroundColor` はクリーム `#FFF6E5`
- `server.iosScheme` は `https`（YouTube の埋め込みが通るように。設計書 8）
- 縦向きだけ。`ITSAppUsesNonExemptEncryption` は false
- `PrivacyInfo.xcprivacy`（追跡なし、UserDefaults の理由 `CA92.1`）を入れ、Xcode の Resources に加える（tjasaifu-app と同じ）
- `src/core/` は変えない。画面（`src/app/screens/*`）も変えない。差し替えは `main.ts` と `native*.ts` だけ
- iPhone の部品の読み込みは静的 import でよい（Node でも読み込むだけなら落ちない）が、呼ぶのは `isNativeApp()` のときだけ
- `npm test`・`npm run typecheck`・`npm run build`・`npm run sync` が通る状態でコミットする
- GitHub への push、リポジトリ作成、`gh secret set`、ワークフローの実行は**この計画ではしない**

## Review Focus

- Preferences の読み戻しが固まる／失敗する → 1.5 秒で見切って起動し、ローカルの値で動く（Task 2）
- 共有シートでキャンセル → エラー扱いにせず静かに戻る（Task 3：`saveText` は投げない。`pickText` はキャンセルで null）
- クリップボードに文字以外（画像）が入っている → 読み取りが失敗しても提案が出ず、落ちない（Task 3）
- `.woff` が dist に残る → 組み立て後に消える（Task 1 のテスト）
- 版番号・ID の食い違い → `tests/app/ios.test.ts` が `capacitor.config.json`・`Info.plist`・`project.pbxproj` を突き合わせる（Task 4）

**Files:**

- Test: `tests/app/native.test.ts`

**Interfaces:**
- `isNativeApp(): boolean`（`Capacitor.isNativePlatform()`。失敗は false）
- `interface PrefsLike { get(o: { key: string }): Promise<{ value: string | null }>; set(o: { key: string; value: string }): Promise<void>; keys(): Promise<{ keys: string[] }> }`
- `SAVE_KEYS = [DATA_KEY, BROKEN_KEY] as const`（core/store の定数）
- `restoreSaves(ls: KeyValueStore, prefs: PrefsLike, timeoutMs = 1500): Promise<void>`・`mirrorStore(ls: KeyValueStore, prefs: PrefsLike): KeyValueStore`・`prepareSaves(timeoutMs = 1500): Promise<void>`・`nativePrefs(): PrefsLike`：SuperShogi の `src/app/native.ts` と同じ作り（鍵が2つなだけ）

### Task 3: iPhone だけの部品の差し替え（共有・ファイル選択・クリップボード・外で開く）

**Files:**
- Create: `src/app/nativeDeps.ts`
- Modify: `src/app/main.ts`（`isNativeApp()` のときだけ差し替え）
- Test: `tests/app/nativeDeps.test.ts`

**Interfaces:**
- `nativeFiles(plugins: { Filesystem: FsLike; Share: ShareLike; FilePicker: PickerLike }): FileDeps`
  - `saveText(name, text)`：`Filesystem.writeFile({ path: name, data: text, directory: 'CACHE', encoding: 'utf8' })` → `Share.share({ title: name, files: [uri] })`。共有のキャンセル（例外）は握って戻る（投げない）
  - `pickText()`：`FilePicker.pickFiles({ types: ['application/json', 'public.json', 'public.text'], readData: true })` → 選ばれなければ null → `files[0].data`（base64）を UTF-8 の文字列に（`atob` と `TextDecoder`）。キャンセルの例外は null
- `nativeClipboardRead(Clipboard: ClipboardLike): () => Promise<string>`（`Clipboard.read()` → `type` が `text/plain` なら `value`、それ以外は `''`。失敗は `''`）
- `nativeOpenExternal(App: AppLike): (url: string) => void`（`App.openUrl({ url })`。失敗は握る）
- 型（`FsLike` など）はこのファイルで最小限を宣言し、本物は `main.ts` で `@capacitor/filesystem` などから渡す
- `main.ts`：`isNativeApp()` なら `files = nativeFiles({ Filesystem, Share, FilePicker })`、クリップボードの `read = nativeClipboardRead(Clipboard)`、`openPlayer` の `deps.openExternal = nativeOpenExternal(App)`、`confirmMode` はそのまま（`window.confirm` は WKWebView でも出る）

`tests/app/nativeDeps.test.ts`：偽の plugin で、書き出しの流れ（writeFile → share に uri が渡る）、共有のキャンセルで投げない、pickText の base64 → 文字列（日本語を含む）、キャンセルで null、クリップボードの `text/plain` と画像（`image/png` → `''`）と失敗、`openUrl` が呼ばれる、を確かめる。
