# クックポップ 計画1：土台と core 実装手順書

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** vite + TypeScript の土台を作り、画面に関係ない計算（料理の形・ルーレットの選び方・作った記録・保存・oEmbed）を `src/core/` にテスト付きで揃える。

**Architecture:** `src/core/` はブラウザも通信も触らない純粋な関数の集まり。乱数・今日の日付・通信は引数で受ける。画面（計画2）はこれらを呼ぶだけ。

**Tech Stack:** Node 24、vite 7.3.7、vitest 3.2.7、TypeScript 5.9.3（SuperShogi と同じ版）

**Spec:** `docs/superpowers/specs/2026-10-23-cookpop-design.md`（5 データ、6 ルーレット、7 中身の分け方、11 確かめ方）

## Global Constraints

- コードのコメント・テスト名・コミットメッセージは日本語
- `src/core/` は `globalThis`・`window`・`fetch`・`Date.now()`・`Math.random()` を直接使わない（引数で受ける）
- 日付は文字列 `YYYY-MM-DD`（端末のローカル時刻で作る）。月は `YYYY-MM`
- ジャンルは `主菜／副菜／汁物／ご飯・麺／おやつ` の5つだけ
- 料理名は 40 文字まで、メモは 400 文字まで（超えた分は切る）
- 保存の鍵は `cookpop.data`、壊れたものの退避先は `cookpop.data.broken`、版番号は `1`
- `npm test` と `npm run typecheck` が通る状態でコミットする
- 自由に決めてよいのは、エラー文言の細かな言い回しと、テストの追加だけ

## Review Focus

- `youtube.com/watch?v=ID&t=30s` のように余計な引数が付いたリンク → ID だけ取れる（Task 2 のテストに含めた）
- 「3つから選ぶ」で候補が2つ以下 → ある分だけ返り、重複しない（Task 4）
- 削除した料理の記録が残っている → 回数・カレンダーの計算で落ちない（Task 3：存在しない recipeId を含む記録）
- 保存した JSON の `recipes` の1件だけ壊れている → その1件だけ捨て、ほかは読める（Task 5）
- oEmbed の返事が JSON でない・項目が欠けている → null になり、呼び元が手入力に落ちられる（Task 6）

### Task 3: 作った記録（core/log.ts）

**Files:**
- Create: `src/core/log.ts`
- Test: `tests/core/log.test.ts`

**Interfaces:**
- Consumes: `Recipe`（Task 2）、`monthOf`（Task 1）
- Produces:
  - `interface CookLog { date: string; recipeId: string }`
  - `addLog(logs: CookLog[], recipeId: string, date: string): CookLog[]`（元を変えず、末尾に足した新しい配列）
  - `countOf(logs: CookLog[], recipeId: string): number`
  - `lastMade(logs: CookLog[], recipeId: string): string | null`（いちばん新しい日付）
  - `logsOn(logs: CookLog[], date: string): CookLog[]`（元の順のまま）
  - `monthCount(logs: CookLog[], month: string): number`
  - `daysMadeIn(logs: CookLog[], month: string): string[]`（重複なし・昇順）
  - `sortByOften(recipes: Recipe[], logs: CookLog[]): Recipe[]`（回数の多い順。同じなら元の順。元の配列は変えない）
  - `sortByStale(recipes: Recipe[], logs: CookLog[]): Recipe[]`（まだ作っていないものが先、次に最後に作った日が古い順。同じなら元の順。元の配列は変えない）
  - `sanitizeLogs(x: unknown): CookLog[]`（配列でなければ空。date が `YYYY-MM-DD` の形・recipeId が空でない文字列のものだけ残す）

### Task 4: ルーレットの選び方（core/picker.ts）

**Files:**
- Create: `src/core/picker.ts`
- Test: `tests/core/picker.test.ts`

**Interfaces:**
- Consumes: `Recipe`（Task 2）、`CookLog`・`lastMade`（Task 3）、`daysBetween`（Task 1）
- Produces:
  - `weightOf(recipe: Recipe, logs: CookLog[], today: string): number`（最後に作った日から today までの日数 d：作っていない → 1、d ≤ 1 → 0、d ≤ 7 → 0.5、それ以外 → 1）
  - `interface PickInput { recipes: Recipe[]; logs: CookLog[]; today: string; rng: () => number; exclude?: string[] }`
  - `pickOne(input: PickInput): Recipe | null`（candidates = recipes から exclude を除いたもの。それが空で recipes が空でなければ exclude を無視。重みの合計が 0 なら全部 1 にする。`rng()` × 合計 を重みの累積で引く（累積が超えた最初の候補）。recipes が空なら null）
  - `pickMany(input: PickInput, n: number): Recipe[]`（pickOne を繰り返し、選んだものを exclude に足していく。重複なし。候補が n 未満ならある分だけ）

### Task 5: 保存とバックアップ（core/store.ts）

**Files:**
- Create: `src/core/store.ts`
- Test: `tests/core/store.test.ts`

**Interfaces:**
- Consumes: `Recipe`・`sanitizeRecipe`・`defaultRecipes`・`findByVideoId`（Task 2）、`CookLog`・`sanitizeLogs`（Task 3）
- Produces:
  - `interface KeyValueStore { getItem(k: string): string | null; setItem(k: string, v: string): void }`
  - `DATA_KEY = 'cookpop.data'`、`BROKEN_KEY = 'cookpop.data.broken'`、`DATA_VERSION = 1`
  - `type Theme = 'auto' | 'light' | 'dark'`
  - `interface Settings { theme: Theme; clipboardCheck: boolean; noAds: boolean; lastClipboardUrl: string }`
  - `DEFAULT_SETTINGS: Settings = { theme: 'auto', clipboardCheck: true, noAds: false, lastClipboardUrl: '' }`
  - `interface AppData { version: 1; recipes: Recipe[]; logs: CookLog[]; settings: Settings }`
  - `initialData(today: string): AppData`（recipes は `defaultRecipes(today)`、logs 空、settings 既定）
  - `sanitizeSettings(x: unknown): Settings`（項目ごとに検証。theme は3つ以外なら `auto`、boolean でなければ既定、文字列でなければ空）
  - `parseData(raw: string): AppData | null`（JSON でない・オブジェクトでない（配列・null も）→ null。recipes は配列でなければ空、1件ずつ `sanitizeRecipe` して null を捨てる。logs は `sanitizeLogs`。settings は `sanitizeSettings`。version は常に 1 で返す。今は版 1 しかないので読み替えなし）
  - `loadData(st: KeyValueStore, today: string): AppData`（無ければ `initialData`。読めなければ raw を `BROKEN_KEY` に退避して `initialData`）
  - `saveData(st: KeyValueStore, data: AppData): void`（`JSON.stringify`）
  - `exportBackup(data: AppData): string`（`JSON.stringify(data, null, 2)`）
  - `importBackup(current: AppData, raw: string, mode: 'replace' | 'merge'): AppData | null`（raw が読めなければ null。replace は読めたものをそのまま。merge は current に、同じ videoId がまだ無い料理を足し、logs は全部末尾に足す。settings は current のまま）
