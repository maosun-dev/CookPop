# 設計：バナー広告と App Store への初めての提出（版 1.0.0）

2026-10-29 にユーザーと決めた内容。元の設計書（2026-10-23-cookpop-design.md の「10. 広告と課金」）の全画面広告と「広告を消す」課金は、今回はやめてバナーだけにする。

## 決めたこと

- 先に App Store に出す。版は 1.0.0
- 収入はバナー広告だけ。全画面広告と「広告を消す」課金は付けない（後の版で足せる）
- バナーは全タブで出す。最初はタブのすぐ上に置いたが、2026-10-30 に実機で「ボタンと近くて不快」とのことで、画面のいちばん上（安全域のすぐ下、TOP_CENTER・margin 0）に移した。画面は --ad-h ぶん下から始まる
- ストアの画面写真は、ユーザーが実機で撮り、私がギンガムの地に一言を添えて仕上げる

## 1. バナー広告

### 作り
- SuperShogi の `src/app/ads.ts` をほぼそのまま持ってくる（`createAds` に偽物のプラグインを渡してテストできる形、出す・隠すを最後に頼まれた状態へ順にそろえる `settle`、追跡の確認 → 広告の同意 → 初期化の順番、開発中の `?adpreview` の仮バナー）
- 部品は `@capacitor-community/admob` を SuperShogi・ワンタップ収支と同じ版で入れる
- 違うところ：位置。SuperShogi は画面のいちばん下。クックポップは**タブのすぐ上**なので、`BOTTOM_CENTER` に `margin` でタブの高さ（64）だけ上げる。プラグインの margin が下の安全域を含むかは実機で確かめる。合わなければ「バナーをいちばん下に置き、タブをバナーの高さだけ上げる」形に切り替える
- バナーの高さは CSS の `--ad-h` に入れ、`.screen` の下の余白とトーストの位置に足す（料理カードやトーストがバナーに隠れないように）

### 出す・隠す
バナーは iPhone 側で画面の上に重ねて描かれる部品なので、Web の画面の都合では隠れない。次のときは隠す：
- 動画を流している間（きめるの結果カードの再生、献立帳の詳細の再生）。YouTube の決まりで、埋め込み動画と広告を並べない
- 下から出る画面（設定シートなど `sheet.ts` で開くもの）を開いている間
- 文字を打っている間（入力欄にカーソルがある間。キーボードとぶつかるため）

「出してよいか」は1か所（例：`bannerWanted()`）で上の3つから決め、変わるたびに `setBannerWanted` に渡す。

### iPhone 側の設定
- Info.plist に `GADApplicationIdentifier`（AdMob のクックポップのアプリ番号）、`NSUserTrackingUsageDescription`（「許可すると、あなたの興味に合った広告が表示されやすくなります。許可しなくても、アプリはすべて使えます。」）、`SKAdNetworkItems`（SuperShogi と同じ一覧）
- 本物のバナー番号が空のあいだは Google のテスト用バナーを出す

### AdMob の準備（アカウントの操作）
- 2026-10-29 に AdMob へ iOS アプリ「クックポップ」とバナー枠「タブの上のバナー」を作った（まだストア未登録なので「要審査」）
  - アプリ番号（Info.plist の GADApplicationIdentifier）：`ca-app-pub-7017663942238206~7979412343`
  - バナー番号（ads.ts の REAL_BANNER_ID）：`ca-app-pub-7017663942238206/4663691703`
- App Store に出たあと、AdMob の「ストアを追加」でストアのアプリ（6826200575）とつなぐ。つなぐまで広告配信は制限される
- app-ads.txt は maosun-dev.com にもうある

## 2. ストアに出す準備

### サイト（`maosun-dev.github.io` リポジトリの `cookpop/`、公開アドレスは maosun-dev.com）
- `cookpop/privacy.html`：プライバシーポリシー
  - 料理の記録・タグ・設定は iPhone の中だけに保存し、外へ送らない
  - 広告は Google AdMob。広告のために端末の識別子などを使う（追跡を許可したときのみ個人に合わせた広告）。Google のプライバシーポリシーへのリンク
  - 動画は YouTube の埋め込み（YouTube API サービス）。YouTube 利用規約・Google プライバシーポリシーへのリンク
  - 動画の題名と画像は、YouTube の公開の仕組み（oEmbed）から取る
- `cookpop/index.html`：サポートページ（使い方・よくある質問・お問い合わせ）。個人のメールアドレスは載せない
- 見た目はクックポップのギンガムに合わせる（作る前に frontend-design を読む）

### アプリの中
- 設定シートの「アプリについて」に、プライバシーポリシーと YouTube 利用規約へのリンクを足す（外で開く）
- 版を 1.0.0 にする

### App Store Connect（URL は必ず maosun-dev.com で書く）
- 名前「クックポップ」、サブタイトル、説明文、キーワード、カテゴリ「フード＆ドリンク」、無料。下書きを私が書き、ユーザーが確認する
- サポート URL：https://maosun-dev.com/cookpop/ 、プライバシーポリシー URL：https://maosun-dev.com/cookpop/privacy.html
- アプリのプライバシー：AdMob の分（端末の識別子・使い方のデータなどを第三者広告に使う、追跡あり）
- 年齢の区分：アンケートに答えて決める
- 審査の人へのメモ：YouTube アプリの共有ボタン →「クックポップ」で登録する使い方、「＋」から URL を貼る使い方
- 画面写真：6.9 インチ用（1320×2868）を3〜5枚。ユーザーが実機で撮った画面を、ギンガムの地に一言を添えて仕上げる。AI っぽい見た目（グラデーション・光・縁取り文字・丸バッジ）にしない。他人の動画のサムネイルが大きく写りすぎないよう、撮るときの料理の選び方を相談する

### 提出
- 全部そろったら、「審査に提出」を押す前にユーザーに確認する

## 確かめ方
- 出す・隠すの切り替え（3つの条件・最後の頼みにそろう・失敗したら高さ0）は vitest で確かめる
- typecheck・build・`npm run sync`・既存のテストが通る
- バナーがタブのすぐ上にきれいに乗るか、動画・シート・入力で隠れるか、追跡の確認が出るかは TestFlight の実機で確かめる（チェック表に足す）
