# クックポップ 設計書

- 日付：2026-10-23
- 状態：設計済み（実装前）
- 元：`kondate-local.html`（単発で作った1枚の試作。機能と見た目の出発点）

## 1. ねらい

「今日なに作る？」を、登録しておいた YouTube の料理動画の中からマスコットがランダムに決めてくれる iPhone アプリ。決めたらその場で動画を見られ、「作った！」と記録できる。

### 誰のため

献立を毎日考えるのが面倒で、YouTube の料理動画をよく見る人。自分（作者）も使う。

### うまくいった状態

- アプリを開いて「きめて！」を押すと、数秒でポン（マスコット）が1品決めてくれる
- 決まった料理の動画がアプリの中で再生できる。再生できないときは YouTube で開ける
- リンクを貼るだけで、題・チャンネル名・サムネイルが自動で埋まって登録できる
- YouTube アプリの共有シートからも登録できる（段階5）
- 「作った！」の記録がカレンダーで見え、アプリを閉じて開き直しても残る
- App Store に出す。広告は動画と別の画面にだけ出す（段階6）

### やらないこと（最初の版）

- 買い物メモ（材料のチェックリスト）、週まとめ「今週のおまかせ」、一覧の検索・並べ替え、家族との共有、Android
- 動画そのものの保存（YouTube の決まりでできない）
- 横向き・iPad への対応（崩れなければよい）

## 3. 画面

下に4つのタブ。

### 3.1 きめる（最初に開く画面）

- 上にポンと吹き出し（時間帯の挨拶や一言）
- 真ん中に大きな「きめて！」ボタン。押すと料理名がパラパラ変わり、最後にポンがはねて止まる
- 絞り込みチップ：すべて／主菜／副菜／汁物／ご飯・麺／おやつ。「お気に入りだけ」。「3つから選ぶ」の切り替え
- 決まったら結果カードがせり上がる：サムネイル、料理名、チャンネル名、メモ、「作った！」「別のにして」「動画を見る」
- 「動画を見る」を押してはじめて YouTube プレーヤー（公式の埋め込み）をカードの中に出す。全画面にもできる。開くまでは埋め込まない（起動が軽く、通信もしない）
- 「3つから選ぶ」のときは3枚の小さなカードが出て、タップで1枚に決まる
- 「作った！」でポンが喜び、記録に1件足す

### 3.2 献立帳（登録した料理の一覧）

- サムネイル付きのカードが並ぶ。ジャンル・お気に入りで絞れる
- 右上の「＋」で登録画面
- カードをタップで詳細：動画（押してから埋め込む）・メモ・作った回数・最後に作った日・編集・削除

### 3.3 登録画面

- リンク欄に貼ると、動画 ID を取り、YouTube の oEmbed（鍵いらずの公式の仕組み）で題・チャンネル名・サムネイルを自動で埋める。通信に失敗したら空のままで手入力に落ちる
- 料理名（自動で埋まった題を直せる）、ジャンル、メモ
- 同じ動画がすでにあるときは「もう登録してあるよ」と出して重ねて登録しない

### 3.4 きろく

- 月のカレンダーに「作った日」の印（ポンの小さな顔）。日をタップでその日の料理
- 「よく作る順」「しばらく作ってない順」の並び
- 今月作った回数で、ポンのおなかの大きさが変わる

### 3.5 設定

- バックアップの書き出し・読み込み、ダークモード（端末に合わせる／明るい／暗い）、広告を消す（段階6）、アプリについて（版・使っている部品の許諾）

### 3.6 割り込み

- クリップボードは勝手に読まない（読むたびに iPhone が「ペーストを許可」と聞くため）。登録画面の「クリップボードから貼る」ボタンを押したときだけ読み、リンク欄に入れる（計画5a）
- 共有シートから来たリンクも同じ登録画面で受ける（計画5b）

### 3.7 初めて開いたとき

- 試作の8品（Koh Kentetsu Kitchen の動画）を最初から入れておく。削除もできる
- ポンが「まずは好きな動画を足してね」と案内

## 4. マスコット「ポン」

- SVG で自作。1ファイルに全身を描き、表情と姿勢は属性（`data-mood`）の切り替えで変える
- 表情：ふつう／考え中（目がぐるぐる）／決めた！（はねる）／うれしい（ほっぺが赤い）／おなかいっぱい／しょんぼり／眠い
- 決めるとき：考え中 → ポンとはねて料理を指す
- 「作った！」：うれしい。今月の回数が多いほどおなかが大きくなる（3段階）
- 登録が5品より少ないとき：しょんぼりして「まだ○品しか知らないよ」
- 挨拶：朝（5〜10時）・昼（10〜15時）・夜（15〜23時）・深夜（眠い）
- アイコン・起動画面も同じ SVG から道具で PNG に書き出す（SuperShogi の `tools/icon` と同じ作り。透明なし 1024×1024）
- 動きは CSS アニメーション。端末の「動きを減らす」がオンなら止める

## 5. データ

### 5.1 料理（Recipe）

| 項目 | 型 | 意味 |
|---|---|---|
| id | string | アプリ内の番号 |
| videoId | string | YouTube の動画 ID |
| url | string | 貼られた元のリンク |
| name | string | 料理名（40文字まで） |
| cat | 主菜／副菜／汁物／ご飯・麺／おやつ | ジャンル |
| channel | string | チャンネル名（空でもよい） |
| thumb | string | サムネイルの URL（oEmbed から。空なら `https://i.ytimg.com/vi/<videoId>/hqdefault.jpg`） |
| memo | string | メモ（400文字まで） |
| fav | boolean | お気に入り |
| addedAt | string | 登録日（YYYY-MM-DD） |

### 5.2 作った記録（CookLog）

- `{ date: "YYYY-MM-DD", recipeId: string }` の一覧。料理の中には持たない
- 作った回数・最後に作った日・月ごとの集計・カレンダーは全部ここから計算する
- 料理を削除しても記録は残す（カレンダーには「削除した料理」と出す）

### 5.3 設定（Settings）

- theme（auto／light／dark）、clipboardCheck（boolean）、noAds（段階6）、lastClipboardUrl（二度聞かないため）

### 5.4 保存

- 1つの JSON `{ version: 1, recipes, logs, settings }` を localStorage の鍵 `cookpop.data` に保存
- iPhone では同じ内容を Preferences にも写す。起動時：localStorage になければ Preferences から戻す。書くたびに両方へ（Preferences は待たない・失敗しても止めない）。SuperShogi の `native.ts` と同じ
- 読むときに版番号を見て読み替える（`migrate`）。壊れていたら初期データに戻し、壊れたものは別の鍵に退避する
- バックアップは同じ JSON を1ファイルで書き出し・読み込み。読み込みは「置き換える」と「足す（同じ動画 ID は飛ばす）」を選べる。iPhone では共有シートで保存、読み込みはファイル選択

## 6. ルーレットの選び方（core/picker.ts）

- 入力：候補の料理、作った記録、今日の日付、乱数（0〜1 を返す関数）、除外する id、人数（1 または 3）
- 重み：昨日か今日作ったものは 0、7日以内は 0.5、それより前かまだ作っていないものは 1
- 重みの合計が 0 なら制限をゆるめ、全部 1 にする（必ず何か出す）
- 「別のにして」：いま出た id を除外して引き直す。候補が1つしかなければそのまま
- 「3つから選ぶ」：重み付きで1つずつ、重複なしで引く。候補が3つ未満ならある分だけ
- 画面はこの関数を呼ぶだけ。乱数と日付を外から渡すのでテストの結果が決まる

## 7. 中身の分け方

```
src/
  core/      画面に関係ない計算だけ（ブラウザも通信も触らない）
    recipe.ts     料理の形・リンクから動画 ID を取る・検証・初期の8品
    picker.ts     ルーレットの選び方
    log.ts        作った記録・回数・最後の日・月ごとの集計・カレンダーの並び
    store.ts      保存の形・版の読み替え・バックアップの往復
    oembed.ts     oEmbed の URL を作り、返事を題・チャンネル・サムネイルに直す（通信は引数）
  app/
    main.ts       起動・保存の戻し・タブの切り替え
    state.ts      いまのデータと「変えたら保存して画面に知らせる」1か所
    native.ts     iPhone だけの部品（Preferences・共有・クリップボード・ファイル）
    screens/      pick.ts / book.ts / form.ts / log.ts / settings.ts / player.ts
    mascot/       pon.svg（絵）・pon.ts（表情・セリフ・動き）
    style.css     色・文字・部品の見た目（変数にまとめる）
tests/           core は全部。画面はつくりを確かめる軽いテスト（jsdom）
tools/icon/      ポンからアイコンと起動画面を作る
docs/            設計書・手順書・実機チェック表
```

決まり
- `core/` は乱数・現在時刻・通信を引数で受ける
- 状態の変更は `state.ts` を通す。画面は `state` を読んで描き、操作は `state` の関数を呼ぶ
- 見た目の色・寸法は `style.css` の変数。マスコットの SVG は1ファイル

## 8. iPhone 化

- Capacitor 8、`webDir: dist`、`ios.contentInset: never`、画面の端は CSS の `env(safe-area-inset-*)`
- ワークフロー `ios-testflight.yml` は SuperShogi のものをそのまま（手動実行だけ、`pull_request_target` は使わない、共同作業者は足さない）
- Secrets：`APPLE_TEAM_ID`・`APPSTORE_API_KEY_ID`・`APPSTORE_API_ISSUER_ID`・`APPSTORE_API_PRIVATE_KEY`。p8 の中身はユーザーが入れる。ほかは前のアプリの記録から
- App Store Connect でのアプリの登録はユーザーが行う
- YouTube の埋め込み：アプリの中は `capacitor://localhost` で動く。YouTube の埋め込みが「エラー153」で再生できないときは、プレーヤーの下の「YouTube で開く」で逃げられる。本当の対策（候補：maosun-dev.com にプレーヤー用の小さなページを置き、アプリからそのページを iframe で読む）は、実機で 153 が出ると分かってから決める。逃げ道として、プレーヤーの失敗を検知して「YouTube で開く」に切り替える仕組みを最初から入れる
- 保存の戻し・写しは SuperShogi の `native.ts` と同じ
- 文字ファイルは .woff2 だけ残す（`tools/strip-woff.mjs` を流用）

## 9. 共有シート（段階5）

- iPhone の Share Extension を足す。手元に Mac がないので、Xcode の設定ファイル（project.pbxproj）への追加は台本（Ruby の xcodeproj か、設定ファイルを直接書く Node の台本）で行い、GitHub の Mac で組み立てるときに毎回同じ結果になるようにする
- 共有されたリンクは App Group（アプリと部品で共有する置き場）に書く。部品は「クックポップに送ったよ」と出して閉じ、できればアプリを開く
- アプリは起動時と前に出たとき（`appStateChange`）に App Group を読み、リンクがあれば登録画面を埋めて開く。読んだら消す
- App Group の読み書きは自作の小さな Swift プラグイン（Lyrivue の whisper プラグインと同じ置き方）

## 10. 広告と課金（段階6）

- ワンタップ収支・TJA採譜台と同じ `@capacitor-community/admob` の全画面広告。「きめて！」を押した回数が3回ごとに、結果カードが出る前に出す。動画を埋め込んでいる画面・献立帳の詳細では出さない（YouTube の決まり）
- 「広告を消す」は `@capgo/native-purchases` で同じ作り
- 開発中はテスト広告、ストアに出す版だけ本物（`ADS_PRODUCTION=1`）
- アプリ・ストアに載せる URL は maosun-dev.com で書く

## 11. 確かめ方

### 自動テスト（vitest）

- リンク解析：youtube.com／youtu.be／shorts／live／embed、余計な引数、違うサイトは null
- 選び方：重み（0／0.5／1）、合計 0 のときのゆるめ、除外、3つ引きの重複なし、候補不足
- 記録：回数・最後の日・月の集計・カレンダーの並び、削除した料理の扱い
- 保存：版の読み替え、壊れた JSON の退避、バックアップの往復、「足す」の重複飛ばし
- oEmbed：URL の組み立て、返事の読み取り、失敗時は空
- 画面：登録画面に貼ると自動で埋まる、「作った！」で記録が増える、タブの切り替え（jsdom）

### 実機（ユーザーの iPhone。チェック表を渡す）

- 起動・文字・アイコン
- 動画がカードの中で再生できる。できないときに「YouTube で開く」に切り替わる
- 登録の自動入力、クリップボード検知
- アプリを閉じて開き直しても料理と記録が残る
- ノッチ・ホームバーと重ならない
- 共有シート（段階5）、広告（段階6）
